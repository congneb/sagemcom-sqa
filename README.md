# Cài đặt

```
pip install pyyaml
pip install paramiko

# Tạo môi trường ảo
python -m venv venv
source venv/bin/activate  # Trên Windows dùng: venv\Scripts\activate

# Cài đặt playwright-pytest
pip install pytest-playwright

# Cài đặt các trình duyệt cần thiết (Chromium, Firefox, WebKit)
playwright install

```
